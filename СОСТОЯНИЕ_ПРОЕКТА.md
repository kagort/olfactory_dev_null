_Дата: 2026-06-18_

## Что сделано

### Инфраструктура
- SQLite БД: таблицы `texts`, `translations`, `sentences`, `alignment`
- `run.py` — единая точка входа для всех команд
- `src/config.py` — пути, словарь `OLFACTORY_WORDS` (ru/en)

### Загрузка текстов
- `src/ingest.py` — загрузка из CSV + `data/books/raw/`
- `src/add_book.py` — добавление отдельной книги через CLI

### Обнаружение ольфакторных предложений
- `src/processing.py` — поиск предложений по OLFACTORY_WORDS
  - Предпроверка через pymorphy3 для RU (быстро)
  - Извлечение concept_phrase через dependency parse (не window ±2 слова)
  - gram_structure вычисляется на concept_phrase, а не на полном предложении

### Синтаксический разбор
- `src/grammar.py`:
  - `parse_ru()` — Stanza (ru_syntagrus)
  - `parse_en()` — spaCy (en_core_web_sm)
  - `extract_concept_phrase_ru()` — полное поддерево ольфакторного токена:
    - рекурсивный обход всех зависимых (включая conj — однородные члены)
    - подъём на уровень вверх если голова — нефинитный глагол (причастие/деепричастие)
  - `extract_concept_phrase_en()` — аналогично через spaCy subtree
- `src/parse_sentences.py` — пакетный пересчёт gram_structure для существующих записей

### Автовыравнивание
- `src/auto_align.py` — LaBSE (cointegrated/LaBSE-en-ru):
  - 1-й проход: RU→EN (`auto_aligned=1`)
  - 2-й проход: EN→RU для непривязанных (`auto_aligned=2`, `--reverse`)
  - Флаги: `--threshold`, `--dry-run`, `--no-window`, `--all`

### Ручная разметка
- `src/manual_review_v2.py` — интерактивный поиск по сырому RU тексту:
  - Пользователь вводит ключевые слова, система ищет по lemma_index + form_index
  - Контекст ±2 предложения вокруг кандидата
  - При сохранении пары:
    - вычисляется cosine_sim через LaBSE
    - вычисляется concept_phrase и gram_structure
    - находится search_word (token_text)
  - Команда `a` — добавить слово в OLFACTORY_WORDS прямо в сессии

### Анализ тональности
- `src/sentiment.py` — обёртка:
  - Если есть локальная модель (`C:\models\roberta-russian-sentiment` / `twitter-roberta-sentiment`) — использует её
  - Иначе — лексиконный fallback

### Экспорт / импорт
- `src/alignment.py` — Excel alignment.xlsx:
  - Лист «Русские»: `№, ru_id, position, sentence, token_text, concept_phrase, gram_structure, тональность, кол-во EN, EN №`
  - Лист «Английские»: `№, en_id, position, sentence, token_text, concept_phrase, тональность, ru_№, sim, авто, translation_shift`
  - Цвета: 🟢 авто 1-й проход, 🟡 авто 2-й проход, 🔵 вручную, 🔴 вручную низкая уверенность
  - Перед экспортом: дозаполняет cosine_sim для пар с NULL через LaBSE
  - `translation_shift`: equivalent ≥0.85 / shift ≥0.65 / significant_shift <0.65
  - Удаление связи при импорте: поставить `0` в столбце `авто`
