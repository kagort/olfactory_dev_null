## 📋 ПАМЯТКА ПОЛЬЗОВАТЕЛЯ

### 🚀 Два способа запуска

---

## 1. КОНСОЛЬ (`console.py`)

**Для чего:** загрузка файлов, ручное выравнивание, быстрые операции

**Запуск:**

```bash
python console.py
```

**Основные пункты меню:**

- `[2]` Загрузка файлов - добавить новый текст
- `[1]` Работа с текстами - посмотреть/удалить тексты
- `[7]` Выравнивание - связать русские и английские предложения
- `[8]` Экспорт CSV - выгрузить данные

**Типичный сценарий:**

```
👉 2 → 1 (загрузить файл)
👉 1 → 6 (посмотреть найденные запахи)
👉 7 → 2 (вручную выровнять с переводом)
👉 8 → 3 (экспортировать всё в CSV)
```

---

## 2. JUPYTER (`notebooks/test.ipynb`)

**Для чего:** анализ данных, графики, статистика, исследования

**Запуск:**

```bash
jupyter notebook notebooks/test.ipynb
```

**Основные команды:**

```python
# Подключение
from notebooks.research import OlfactoryResearch
research = OlfactoryResearch("data/olfactory.db")

# Посмотреть данные
df = research.get_texts_dataframe('ru')
df.head()

# Графики
research.plot_smell_distribution('ru')
research.plot_top_smells('ru', n=20)
research.compare_languages()

# Поиск
results = research.search_by_smell("яблоко", 'ru')
results[['title', 'sentence']]

# Экспорт
research.export_to_csv('olfactory_ru', 'данные.csv')
```

**Типичный сценарий:**

- Ячейка 1: загрузить research
- Ячейка 2: получить статистику
- Ячейка 3: построить графики
- Ячейка 4: сохранить результаты


### 🔄 Когда что использовать (исправлено)

| Задача | Консоль | Jupyter |
|--------|---------|---------|
| Загрузить новый текст | ✅ (меню) | ✅ (через `processor`) |
| Посмотреть список текстов | ✅ | ✅ |
| Выровнять предложения вручную | ✅ | ❌ (только кодом) |
| Построить график | ❌ | ✅ |
| Посчитать статистику | ✅ (ограниченно) | ✅ (подробно) |
| Найти все упоминания слова | ✅ | ✅ |
| Сравнить языки | ❌ | ✅ |
| Экспорт в CSV | ✅ | ✅ |
| Сохранить результаты исследования | ❌ | ✅ (весь notebook) |
| Пакетная обработка | ✅ (меню) | ✅ (цикл в ячейке) |

---

### 💡 Вывод

Jupyter умеет всё то же, что и консоль, плюс графики.
Консоль удобна, когда не хочется писать код, а просто тыкать в меню.

---

### ⚠️ Важно

**После изменения кода в файлах (.py):**

- Для консоли: просто перезапустить `console.py`
- Для Jupyter: **Kernel → Restart** (обязательно!)

**Где данные:** `data/olfactory.db` - резервная копия 

**Где словарь запахов:** `src/processors/processors.py`, переменная `OLFACTORY_WORDS`
