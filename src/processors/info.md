## 📁 Файл: `src/processors/processors.py`

### Назначение

Обрабатывает текстовые файлы, находит предложения с запахами и сохраняет их в базу данных.

### Глобальные переменные

| Переменная | Назначение                                                                                           |
| -------------------- | -------------------------------------------------------------------------------------------------------------- |
| `_nlp_cache`       | Кэш для загруженных моделей spaCy (чтобы не грузить каждый раз) |
| `OLFACTORY_WORDS`  | Словарь слов-запахов по языкам                                                       |

---

### Класс `FileProcessor`

#### Конструктор

```python
def __init__(self, db):
    self.db = db                    # экземпляр OlfactoryDB
    self.supported_languages = ['ru', 'en']
```

#### Приватные методы (внутренние)

| Метод                                                   | Назначение                                        | Вход                                                          | Выход                                                               |
| ------------------------------------------------------------ | ----------------------------------------------------------- | ----------------------------------------------------------------- | ------------------------------------------------------------------------ |
| `_get_nlp_model(language)`                                 | Загружает модель spaCy для языка     | `'ru'` или `'en'`                                          | модель spaCy                                                       |
| `_split_sentences(text)`                                   | Разбивает текст на предложения   | текст                                                        | список предложений                                      |
| `_extract_context(words, word_pos, window=3)`              | Извлекает контекст вокруг слова | список слов, позиция                             | (левый_контекст, правый_контекст, фраза) |
| `_analyze_sentence(sentence, text_id, position, language)` | Анализирует одно предложение      | предложение, ID текста, позиция, язык | словарь с данными или None                             |

#### Публичные методы

| Метод                            | Назначение                                                   | Когда использовать                                                         |
| ------------------------------------- | ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| `process_file(file_path, ...)`      | Обработать файл с диска                            | Основной метод для загрузки новых текстов               |
| `process_text(text, ...)`           | Обработать текст напрямую                       | Для ручного ввода или текста из другого источника |
| `reanalyze_text(text_id, language)` | Переанализировать существующий текст | После расширения словаря запахов                               |

---

### Параметры `process_file` и `process_text`

| Параметр         | Тип | Обязательный | Назначение                                                                       |
| ------------------------ | ------ | ------------------------ | ------------------------------------------------------------------------------------------ |
| `file_path` / `text` | str    | да                     | Путь к файлу или сам текст                                            |
| `title`                | str    | нет                   | Название произведения                                                  |
| `author`               | str    | нет                   | Автор                                                                                 |
| `year`                 | int    | нет                   | Год издания                                                                      |
| `language`             | str    | нет                   | Язык (если не указан, определяется автоматически) |
| `is_original`          | bool   | нет                   | `True` - оригинал, `False` - перевод                                    |
| `original_lang`        | str    | нет                   | Язык оригинала (для перевода)                                      |
| `original_id`          | int    | нет                   | ID оригинала в БД (для перевода)                                    |

### Возвращаемое значение

```python
{
    'text_id': int,                 # ID сохраненного текста
    'language': str,                 # язык
    'total_sentences': int,          # всего предложений в тексте
    'olfactory_sentences': int,      # найдено предложений с запахами
    'olfactory_words': int            # всего слов-запахов (для process_file)
}
```

---

### Схема работы `process_file`

```
Чтение файла
    ↓
Сохранение текста в БД (texts_*)
    ↓
Разбивка на предложения (_split_sentences)
    ↓
Для каждого предложения:
    Быстрая проверка по словарю
    ↓
    Если есть кандидат → анализ через spaCy
    ↓
    Извлечение контекста (_extract_context)
    ↓
    Сохранение в список
    ↓
Сохранение всех найденных предложений в БД (olfactory_*)
```

### Структура данных для `smell_words`

Каждое найденное слово-запах сохраняется как словарь:

```python
{
    'word': 'пахло',           # слово как в тексте
    'lemma': 'пахнуть',        # начальная форма
    'pos': 'VERB',              # часть речи
    'position': 3,              # позиция в предложении
    'left_context': 'В комнате', # слова слева
    'right_context': 'яблоками', # слова справа
    'concept': 'В комнате пахло яблоками'  # вся фраза
}
```

### Пример использования

```python
from src.processors import FileProcessor
from src.database import OlfactoryDB

# Создаём базу и процессор
db = OlfactoryDB("data/olfactory.db")
db.init()
processor = FileProcessor(db)

# Загружаем файл
result = processor.process_file(
    file_path="books/tolstoy-war.txt",
    title="Война и мир",
    author="Лев Толстой",
    year=1869,
    language="ru",
    is_original=True
)

print(f"Загружен текст ID {result['text_id']}")
print(f"Найдено {result['olfactory_sentences']} предложений с запахами")

# Если потом расширили словарь - переанализировать
processor.reanalyze_text(result['text_id'], "ru")

db.close()
```

### Важные замечания

1. **Языки** - поддерживаются только `'ru'` и `'en'` (см. `supported_languages`)
2. **Модели spaCy** - должны быть установлены отдельно:
   ```bash
   python -m spacy download ru_core_news_sm
   python -m spacy download en_core_web_sm
   ```
3. **Автоопределение языка** - отключено (метод закомментирован), язык нужно указывать явно
4. **Сохранение** - использует `db.olfactory.add()`, который должен быть в `OlfactoryManager`
