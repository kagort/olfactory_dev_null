## 📁 Файл: `src/database/managers.py`

### Назначение

Содержит классы-менеджеры для создания таблиц и выполнения операций с данными.

### Классы и их применение

| Класс           | Когда использовать                                     | Основные методы                                                                                                |
| -------------------- | ----------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `TableManager`     | При инициализации БД, один раз                 | `create_all()` - создаёт все таблицы                                                                      |
| `TextManager`      | Для всех операций с текстами                    | `add_original()`, `add_translation()`, `get_by_id()`, `get_by_language()`, `get_translations()`, `delete()`      |
| `OlfactoryManager` | Для работы с найденными запахами            | `add_many()`, `get_by_text()`, `search_by_smell_word()`, `update()`, `delete()`, `align()`, `get_statistics()` |
| `DummyDict`        | Заглушка, если словарь не используется | `check()`, `get_all()`, `add()`                                                                                        |

### Важные замечания

- Языки должны быть согласованы между менеджерами
- Выравнивание (`align`) работает только для русско-английских пар
- `smell_words` хранится в формате JSON

## 📁 Файл: `src/database/core.py`

### Назначение

Базовый класс для подключения к SQLite и выполнения запросов.

### Класс `Database`

| Метод               | Что делает                     | Возвращает                                                                         |
| ------------------------ | --------------------------------------- | -------------------------------------------------------------------------------------------- |
| `connect()`            | Открывает соединение | Объект соединения                                                            |
| `close()`              | Закрывает соединение | None                                                                                         |
| `execute(sql, params)` | Выполняет запрос         | Для SELECT: список словарей, для INSERT: lastrowid, иначе: rowcount |

### Использование

```python
db = Database("data/olfactory.db")
result = db.execute("SELECT * FROM texts_ru")
db.close()
```

## 📁 Файл: `src/database/__init__.py`

### Назначение

Объединяет все компоненты БД в единый интерфейс.

### Класс `OlfactoryDB`

| Атрибут | Что содержит                                              |
| -------------- | -------------------------------------------------------------------- |
| `db`         | Экземпляр `Database` для прямых запросов |
| `tables`     | Экземпляр `TableManager`                                  |
| `texts`      | Экземпляр `TextManager`                                   |
| `olfactory`  | Экземпляр `OlfactoryManager`                              |
| `dict`       | Заглушка `DummyDict`                                       |

### Методы

- `init()` - создаёт все таблицы
- `close()` - закрывает соединение

### Стандартный сценарий использования

```python
from src.database import OlfactoryDB

# 1. Создаём объект
db = OlfactoryDB("data/olfactory.db")

# 2. Инициализируем таблицы
db.init()

# 3. Работаем с данными через менеджеры
db.texts.add_original('ru', 'Заголовок', 'Автор', 2024, 'Текст...')
olfactory_data = db.olfactory.get_by_text('ru', 1)

# 4. Закрываем соединение
db.close()
```
